# 公开演示站设计与实施计划 — 2026-10-11

## 用户授权与目标
用户选择公开演示版。任何人无需 GitHub 或 MES 账号打开页面，使用合成演示数据；生产源码和数据库保持私有。

## 方案
复用现有 web/reference 静态原型，不改真实 MES。新建公开仓库 xaigin-mes-demo，通过 GitHub Pages 发布。仅上传 HTML/CSS/JS、地图几何和文档测试；无后端、数据库、上传附件、密码或密钥。
演示涵盖 14 个导航页面：运营、生产、客户资产、库存、采购、合同、财务、人员、权限、审计、扫码、设备绑定、标签、扫码记录。
前端资源允许浏览器读取，访客无仓库写入权限。部分按钮提示原型占位，二维码为装饰预览，修改仅存在页面内存，刷新恢复。不能描述为完整真实 MES 或实时机房数据。
